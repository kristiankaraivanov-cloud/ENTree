# Contributing

Open an issue with a reproducible example or submit a focused pull request. Keep the native filesystem bridge narrow and preserve the scan/review/confirmation workflow. Include regression coverage for scanner or recycling changes.

Run `npm ci`, `npm test`, and `npm run check`. Use `npm start` for native behavior and `npm run preview` for sample-data UI development. Never commit local file listings, credentials, or settings.

Please report unsafe recycling behavior privately through GitHub's private vulnerability reporting if enabled. Until then, contact the repository owner without attaching private file paths to a public issue.
